# 🌱 Agripal – AI-Powered Smart Agriculture Platform

Agripal is an AI-powered smart agriculture platform developed as a Master's graduation project. The platform helps farmers improve crop management through artificial intelligence, computer vision, and intelligent decision support tools.

---

## 📌 Overview

Agripal combines mobile technologies and artificial intelligence to provide a complete smart farming solution. It integrates multiple AI modules into a single platform, making agricultural monitoring and decision-making more efficient.

---

## ✨ Features

- 🌿 Plant disease detection using deep learning
- 🤖 AI-powered chatbot for agricultural assistance
- 📊 Smart crop monitoring
- 🧠 Intelligent decision support
- 👤 User authentication
- 📱 Cross-platform mobile application built with Flutter
